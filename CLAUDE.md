# leaguesapp

Amateur sports league platform for Palestine. Arabic-first, RTL. Web now, Expo mobile later.

- `docs/superpowers/specs/2026-09-10-leaguesapp-design.md` — the design. Read before any feature work; it settles the data model and the core decisions.
- `docs/superpowers/plans/` — implementation plans, one per group of spec slices. Execute the active plan task by task with `superpowers:subagent-driven-development`.
- `docs/STACK.md` — stack rationale. Read only when changing the stack.

## Gates

- **New scope** the spec does not already cover (a feature, a screen, a behavior change) → invoke `superpowers:brainstorming` first, stop at its approval gate. Work already described by a plan or the spec skips this — just execute it.
- **Any UI work** → invoke `impeccable:impeccable`. `DESIGN.md` at repo root is the authority: dark-first, emerald accent, mobile-first. Palette, tokens, and layout rules live there — read it, do not restate it in chat.
- **Session ending, context full, or usage limit hit** → `/handoff` before stopping, so the next session resumes clean.

## Token rules

Global config already covers graphify-first and RTK. Project-specific:

- Read `src/types/database.ts` (generated by `supabase gen types typescript`) for the schema. Never read migrations to recall a column name.
- One vertical slice per session.
- Server Actions, not API routes.
- Server Components and RLS replace a service layer, repository pattern, DTOs, and any state-management library. Write conventional Next.js — a custom abstraction is re-read every session forever.

## Stack

Next.js 15 App Router · TypeScript · Tailwind v4 · shadcn/ui · Supabase (Postgres, Auth, Storage, RLS) · next-intl

- Auth v1: **phone + password**. No SMS OTP — it costs money.
- Payments: **records only, admin-confirmed**. Cash, bank transfer, Reflect, iBuraq. No gateway.
- Notifications (slice 7): **OpenWA** self-hosted WhatsApp, outbound only, five templated messages. No inbound parsing. Never auth. `docs/OPENWA.md`.

## Arabic / RTL — non-negotiable

- All user-facing copy in Arabic, Palestinian dialect. Not MSA, not translated English.
- `dir="rtl"`. Logical properties only: `ms-` `me-` `ps-` `pe-` `start` `end`.
- Western digits (1, 2, 3), `tabular-nums` for figures. Local date formats.
- Strings live in next-intl message files, never hardcoded in JSX.

## Scale later, columns now

`sport_id`, `city_id`, `currency` on the relevant tables from the first migration. No abstraction layer over them until sport #2 exists.

## Do not build

Payment gateway · automated venue booking · live match mode · ELO rating · transfer market · knockout tournaments · AI scheduling · a separate admin app. Admin is role-gated routes in the same app.

## Before claiming done

Run `npx tsc --noEmit`. Leave one assert-based check behind for any non-trivial logic.
